HAPPY BIRTHDAY WEBSITE — FOR RIMJHIM (ANSHU)

1) PERSONALIZE THE COUNTDOWN
Open script.js and change:
const BIRTHDAY_DATE = "2026-12-25T00:00:00";
Use the birthday date in YYYY-MM-DDTHH:MM:SS format. Example:
const BIRTHDAY_DATE = "2026-11-20T00:00:00";

2) ADD YOUR PHOTOS
Put your own image files in assets/photos and name them exactly:
memory-1.jpg
memory-2.jpg
memory-3.jpg
You can use .jpg images. If your images are .png, update the matching filenames in index.html.

3) ADD MUSIC
Put an MP3 you have permission to use in assets/music and name it:
birthday-song.mp3
Browsers require a click before music can start, so the Play music button is intentional.

4) CHANGE THE LETTER
Open index.html and edit the text inside the letter-text and extra-letter paragraphs.

5) TEST
Open index.html in a browser. The website uses Google Fonts from the internet; if unavailable, fallback fonts will display.

6) PUBLISH FREE WITH GITHUB PAGES
- Sign in to GitHub.
- Create a PUBLIC repository named birthday-surprise.
- Upload the contents of this folder (index.html, styles.css, script.js, README.txt, and assets folder). Do not upload the ZIP itself.
- In the repository, open Settings > Pages.
- Under Build and deployment, choose Deploy from a branch.
- Choose branch main and folder /(root), then Save.
- Wait a minute or two. Your site should appear at:
  https://rimjhimeren-dev.github.io/birthday-surprise/

Keep the repository Public for free GitHub Pages hosting on GitHub Free.
