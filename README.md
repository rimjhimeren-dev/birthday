# A birthday surprise for Rimjhim (Anshu) ♡

A small, romantic birthday page built with plain HTML, CSS and JavaScript.

## Birthday date
The countdown is set to **8 November 2026 at midnight Nepal time**. Change `BIRTHDAY_DATE` in `script.js` if needed.

## Add your own photos and music
Create these folders and add your own files:
- `assets/photos/memory-1.jpg`
- `assets/photos/memory-2.jpg`
- `assets/photos/memory-3.jpg`
- `assets/music/birthday-song.mp3`

The music button will work after the MP3 is added. Photos are optional.

## Deployment
This repository includes a GitHub Actions workflow at `.github/workflows/pages.yml`. It deploys the site to GitHub Pages whenever you push to `main`.

After the first workflow run, open **Settings → Pages** in the repository and confirm the source is **GitHub Actions** if GitHub asks you to select a source.

Your expected site address is:
https://rimjhimeren-dev.github.io/birthday/
